title: Groq
description: Use a Groq API key to look words up in Kotiko.
---

Groq runs open models quickly, with a free tier.

## Get a key

1. Open [Groq's keys page](https://console.groq.com/keys) and sign in.
2. Select **Create API Key**, name it "Kotiko", and copy it. It starts with `gsk_`.

## Paste it into Kotiko

1. Open Kotiko's **Settings** (from the toolbar popup), then **Word lookups**.
2. Under **Look words up with**, choose **Groq**.
3. Paste the key into **Groq key** and select **Save key**.
4. Select **Test**. "It works" means Kotiko can look words up.

Your key stays in this browser, where web pages can't read it. It's never copied to other
devices or into backups. Kotiko sends it only to Groq, at `https://api.groq.com/openai/v1`.
