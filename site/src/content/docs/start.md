title: Get started
description: Your first word in Kotiko, with or without an AI key, in about a minute.
---

When you install Kotiko, it opens a welcome page. It asks three things: the languages you
read, how to look words up, and the first word you'd love to learn. This page explains each
step. You can do everything later from Kotiko's **Settings** too.

## 1. The languages you read

Kotiko swaps words on pages written in the languages you read. It starts with your
browser's languages. Tick the ones you read, or select **Another** to add one; you can have
up to four.

A word's meaning is kept in your language: a Spanish reader learning Japanese sees 犬 on
Spanish pages where "perro" was; an English reader sees it where "dog" was.

## 2. How Kotiko looks words up

Pick one of three ways. You can change it at any time in **Settings**, **Word lookups**.

### No key: type words with their meaning

Select **Skip: I'll type meanings myself**. You add words as `word = meaning`, like
`perro = dog` or `спасибо (spasibo) = thanks`. Nothing leaves your browser. This always works,
even with a key set up.

### A free OpenRouter key (recommended)

An AI looks words up for you, so you can ask in your own words: "how do you say cat in
Japanese", "hola", "dog in Arabic". OpenRouter gives free access to several AI models.

1. Select **Connect OpenRouter (free)**. OpenRouter opens in a new tab.
2. Sign in to OpenRouter, or create an account, and allow Kotiko's request.
3. OpenRouter sends you back to a Kotiko page that says "Connected". Close it; the welcome
   page now says "Connected to OpenRouter, free models."

Already have a key? Select **Paste a key instead** and paste it. **Get a free key** opens
OpenRouter's keys page if you'd rather make one yourself.

[Step by step, with what the free tier allows](/providers/openrouter/).

### Another service, your own model or your own server

Select **Another service or my own model** to use OpenAI, Anthropic, Google Gemini, Groq,
Ollama, LM Studio or any OpenAI-compatible service: see [Choosing a service](/providers/).
Select **My Kotiko server** if you run [your own server](/server/).

## 3. Your first word

Kotiko asks: "What's the first word you'd love to learn?" Type a word or a question in any
language, then select **Ask**:

| You type | Kotiko finds |
|---|---|
| `how do you say hello in Japanese` | こんにちは (konnichiwa) |
| `hola` | the Spanish word for hello |
| `dog in Arabic` | كلب (kalb) |
| `merci = thank you` | merci, with your meaning, no lookup needed |

Check the result and select **Make it my first word**. Kotiko shows how the word will look on
a page, and from now on it shows up wherever the word in your language does. Select **Try it
on a page** to see it on Wikipedia.

## 4. Pin Kotiko

Kotiko's toolbar button is where you add words, turn Kotiko on and off, and pause it on a
site.

- **Chrome, Edge and Brave:** select the puzzle piece, then the pin next to Kotiko.
- **Firefox:** select the extensions button, then the gear next to Kotiko, then **Pin to
  Toolbar**.
