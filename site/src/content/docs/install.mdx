Kotiko runs in Chrome, Edge, Brave and other Chromium browsers, and in Firefox. It's free.

## Chrome, Edge and Brave

<StoreLinks only="chrome" />

{stores.chrome ? (
  <Steps>
    <ol>
      <li>Open <a href={stores.chrome}>Kotiko in the Chrome Web Store</a>. Edge and Brave use the same store.</li>

## From source

Every release on GitHub has the same packages the stores get. You can install one by hand,
for example before a store listing exists or to try a new version early. Updates don't
arrive by themselves this way: install each new release the same way.

### Chrome, Edge and Brave from source

<Steps>

1. Download `kotiko-chrome-<version>.zip` from the [latest release](https://github.com/ScriptKittyOS/kotiko/releases).
   To make sure it's genuine, see [Checking a download](/install/verify/).

2. Unzip it into a folder you'll keep. The browser loads Kotiko from that folder each time
   it starts, so don't move or delete it.

3. Open `chrome://extensions` (Edge: `edge://extensions`, Brave: `brave://extensions`).

4. Turn on **Developer mode** (top right in Chrome and Brave, on the left in Edge).

5. Select **Load unpacked** and choose the folder from step 2.

6. Pin Kotiko: select the puzzle piece in the toolbar, then the pin next to Kotiko. Then
   [get started](/start/).

</Steps>

To update, unzip the new release over the same folder, then select the reload button on
Kotiko's card in `chrome://extensions`. Keep the same folder: the browser ties the
extension's settings to it.

### Firefox from source

<Steps>

1. Download `kotiko-firefox-<version>.zip` from the [latest release](https://github.com/ScriptKittyOS/kotiko/releases).

2. Open `about:debugging#/runtime/this-firefox`.

3. Select **Load Temporary Add-on…** and choose the zip file.

4. Open `about:addons`, select Kotiko, open its **Permissions** tab and allow access to all
   websites.

</Steps>

<Aside type="caution">
Firefox removes temporary add-ons, and everything they saved, when it restarts. Use this to
try Kotiko; for everyday use, wait for the Firefox Add-ons listing.
</Aside>

### From the repository

Developers can load the `extension` folder of a clone of the repository directly. See
[Developer setup](/contribute/setup/).
